```
Wave 0 (前置 / 立即执行):
  wire-mmu-fw-callback-ioctls-to-active-dispatch (P0)
    -- 派发表 + handler 实现修复 (kNumIoctls 36->38)

```

**理由**:

1. **Wave 0 = wire-mfu** 是 P0 impl 修复, 建立活跃派发表正确性基线.
   其余 3 个 change 都是测试类 (`category=core-test`), 技术上可独立运行,
   但**与 wire-mfu 串行**确保:
   - add-abi 一致性检查在派发表修复**后**运行才有意义 (验证 kNumIoctls=38)
   - add-e2e / strengthen 的 E2E 测试在派发表扩展**后**能覆盖新 ioctl
2. **3 个测试 change 之间可并行**: 互不重叠文件 (除前述 false-positive), 互不阻塞.
3. 优先级 P0/P1/P1/P2 决定执行次序 - 同 wave 内按 priority 排序; wave 间有硬依赖.
